使用说明

在 GitHub 链接前加上本站地址即可加速，支持带协议头或不带协议头。

例如：本站地址/https://github.com/user/repo/releases/download/v1.0/file.zip

Git Clone:

git clone 本站地址/https://github.com/user/repo.git

文件夹下载（自动打包为 ZIP）:

本站地址/https://github.com/user/repo/tree/main/folder

Releases 列表:

本站地址/https://github.com/user/repo/releases
